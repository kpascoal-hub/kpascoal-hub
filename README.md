# **Matheus Pascoal**
**`Ethical Hacking`** **`Pentester`** **`Estudante de Cibersegurança Ofensiva`** 

Sou desenvolvedor com base em back-end e banco de dados, direcionando minha atuação para segurança da informação após vivência prática na criação de uma startup em 2025, onde lidei com organização, integridade e possíveis falhas de exposição de dados. Participei de projetos como um robô controlado via Bluetooth para o desenvolvimento de um sistema web completo, passando a analisar aplicações sob a ótica de vulnerabilidades e riscos. Atualmente, foco em cibersegurança, com interesse em exploração prática, identificação de falhas e análise de segurança em sistemas reais.
